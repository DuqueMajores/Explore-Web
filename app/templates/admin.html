Entendendo a Arquitetura: Servidor vs. Navegador vs. GitHub Pages

Como João e Maria veem a mesma página?

O arquivo SQLite permanece exclusivamente no servidor Flask. Quando João (em São Paulo) acessa um card, o servidor cria o registro no SQLite central. Quando Maria (no Rio de Janeiro) acessa o portal, a requisição dela consulta exatamente o mesmo arquivo SQLite no servidor.

Papel do Navegador (Cookies)

O navegador não armazena a base de dados principal. Cookies são usados apenas para identificar anonimamente o leitor (noticias_reader_id). O banco oficial dos dados é sempre o SQLite no servidor.

Por que NÃO funciona no GitHub Pages?

O GitHub Pages fornece apenas hospedagem de arquivos estáticos (HTML/CSS/JS). Ele não executa processos Python/Flask nem oferece sistema de arquivos com escrita persistente. Por isso, a aplicação requer um servidor real (Docker/VPS/Render com volume de disco) para reter o arquivo SQLite.
